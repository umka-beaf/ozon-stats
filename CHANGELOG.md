# Changelog

Формат на основе [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [Semantic Versioning](https://semver.org/lang/ru/).

## [1.1.0] - 2026-11-12

### Добавлено
- Слой поверх сайта Ozon (опции в панели расширения, по умолчанию выключены):
  - скрытие рекламных и промо-блоков;
  - раздельное скрытие зачёркнутых цен и плашек скидки;
  - цена за килограмм или литр по характеристикам товара (`webAspects`);
  - обрезка названия карточки до двух строк, полный текст — в родном тултипе;
  - тёмная тема сайта (в режиме `auto` — по системной);
  - широкий режим для мониторов шире 1600 px: контейнер с товарами
    расширяется до 2000 px, на главной карточки растягиваются на 1/5 ширины,
    на выдаче остаётся 4 в ряд, на карточке товара карусели идут на всю ширину.
- Тёмная тема панели статистики — только внутри панели, страница не
  инвертируется.
- Доступность панели: роли и aria-атрибуты у элементов, видимый фокус.

### Изменено
- Статусы заказов: «Доставим сегодня» и «Ожидаем сегодня» относятся к «в пути»,
  «Ожидает оплаты» не считается готовым к выдаче, разбивка по статусам
  склоняется по-русски.

### Исправлено
- Сетка карточек главной и скидки после перерисовки страницы.
- Закреплённая шапка в тёмной теме: при прокрутке Ozon включает её сменой
  класса у существующего узла, а проход по DOM запускался только на вставку
  узлов. Шапка оставалась светлой под светлыми токенами, пока не подгрузятся
  карточки; теперь её пометка обновляется по событию прокрутки.
- Точки количества фото в карточках: при листании фото React переписывает
  class у точек и затирает нашу метку, из-за чего неактивные точки снова
  пропадали на тёмной подложке. Ряд точек теперь наблюдаем отдельно и метку
  обновляем при смене класса.

## [1.0.1] - 2026-10-17

### Исправлено
- Переход по клику на карточку заказа: Ozon сменил имя query-параметра в
  ссылке на заказ (`order=` → `orderNumber=`) и убрал поле `automatizationId`,
  на котором держалось извлечение номера заказа — клик молча переставал
  работать. Номер теперь берётся из прямой ссылки у шеврона заказа.

## [1.0.0] - 2026-09-02

### Добавлено
- Первый публичный релиз — форк расширения [Ozon Stats — Статистика
  заказов](https://chromewebstore.google.com/detail/dpiekoogdgfdnamkekndojoplgomelkm)
  автора luckydawnbastard, поверх базового набора (сумма трат, количество
  заказов, дата регистрации, разбивка по годам, график) добавлено:
  - фото, статусы и дата доставки активных заказов;
  - адрес ПВЗ/постамата, копирование номера заказа по клику;
  - клик по карточке заказа — переход к заказу на Ozon;
  - бейдж на иконке расширения с числом активных заказов;
  - уведомления об изменении статуса заказа;
  - кэш последних данных для мгновенного отображения панели.
