# Changelog

Формат на основе [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.1] - 2026-10-17

### Исправлено
- Переход по клику на карточку заказа: Ozon сменил имя query-параметра в
  ссылке на заказ (`order=` → `orderNumber=`) и убрал поле `automatizationId`,
  на котором держалось извлечение номера заказа — клик молча переставал
  работать. Номер теперь берётся из прямой ссылки у шеврона заказа.

## [1.0.0] - 2026-09-02

### Добавлено
- Первый публичный релиз — форк расширения [Ozon Stats — Статистика
  заказов](https://chromewebstore.google.com/detail/dpiekoogdgfdnamkekndojoplgomelkm)
  автора luckydawnbastard, поверх базового набора (сумма трат, количество
  заказов, дата регистрации, разбивка по годам, график) добавлено:
  - фото, статусы и дата доставки активных заказов;
  - адрес ПВЗ/постамата, копирование номера заказа по клику;
  - клик по карточке заказа — переход к заказу на Ozon;
  - бейдж на иконке расширения с числом активных заказов;
  - уведомления об изменении статуса заказа;
  - кэш последних данных для мгновенного отображения панели.
